# 🌐 Personal Portfolio Website

A responsive and user-friendly personal portfolio website developed using **HTML5** and **CSS3**. This project showcases my education, technical skills, projects, and contact information in a clean and professional layout.

## 📌 Features

- Responsive Design
- Semantic HTML5 Structure
- Clean and Modern UI
- About Me Section
- Skills Section
- Projects Section
- Contact Page
- Accessibility-Friendly Design

## 🛠️ Technologies Used

- HTML5
- CSS3

## 📂 Project Structure

```
Portfolio/
│── index.html
│── about.html
│── projects.html
│── contact.html

    └── profile.jpeg
```

## 🚀 Getting Started

1. Clone the repository:

```bash
git clone https://github.com/your-username/Portfolio.git
```

2. Open the project folder.

3. Open `index.html` in your browser.
